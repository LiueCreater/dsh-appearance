# Liue 的大傻鱼背景主题

> `dsh-appearance` — 给 [DeepSeek Harness](https://github.com/deepseek-ai) 换一张自己的脸：整窗壁纸、卡片玻璃、图片取色，以及侧栏余额与用量。

一个 DSH 外观插件。上传图片或视频作为整个界面的底层背景，拖动裁切、缩放、调模糊；给侧栏按钮、对话内容、输入框和弹窗套上圆角玻璃；从壁纸里自动提取主题色；浅色/深色各自一套样式；设置可导出为带校验的样式包。

![icon](icon.png)

## 功能

### 壁纸

- 图片（PNG / JPEG / GIF / WebP / AVIF）与视频（MP4 / WebM / OGG），单文件 ≤ 80 MB。
- 上传、拖放、粘贴都可以；大于 3840px 的图片会先在浏览器里压缩。
- 预览里直接拖动定位，滚轮或滑块缩放（1–4×），可选「填满 / 适应」。
- 整体模糊 0–32px，支持**高斯**（CSS blur）与**线性**（SVG 横向模糊），只模糊壁纸层。
- 视频静音循环，Host 端支持 HTTP Range，不会一次性把大文件读进内存。

### 玻璃

- 四种卡片质感：**无 / 半透明 / 磨砂 / 液态**；强度 0–100、圆角 0–28px。
- 玻璃只加在“卡片”上：侧栏的新对话、插件、工作区按钮，对话区的回答、思考/工具调用过程、输入框、用量条，插件面板与弹窗菜单。其余区域和顶部栏保持透明，直接露出壁纸。
- 分区开关：侧栏按钮、对话内容、插件面板、弹窗与菜单；AI 回答的玻璃底可单独开关。
- 输入框上方的对话文字用 mask 渐隐，不铺纯色遮罩；回答的圆角边框不会被渐隐裁掉。

### 主题色

- 上传壁纸后自动量化取色，最多 5 个主色。
- 取色器、HEX、RGB 手动指定；只覆盖 `--dsw-alias-brand-primary`，由插件生成对应的浅色/深色两版。
- 浅色与深色主题各自保存主题色与调色板，切换主题时使用对应一套，互不覆盖。

### 侧栏底部

- 余额（官方 API Key 优先，失败回退 DeepSeek 账号登录态）。
- 今日全部 token / 本对话 token，以及按峰谷价估算的费用。
- 每轮对话结束立即刷新，有页面订阅时每 60 秒刷新；缓存 25 秒。
- 「重新加载界面」与「退出并重启」说明按钮。
- 可关闭 token/花费显示，关闭后只剩两个按钮和一张贴合按钮的小玻璃卡。

### 其他

- 输入框内容超过视口约 45% 时出现折叠按钮，一键收回 168px。
- 设置页顶部固定「快速更改 / 上传新样式」两栏。
- 样式包 ZIP 导出/导入：固定 magic + 整体 SHA-256 + 每张壁纸 SHA-256，全部校验通过才应用。

## 安装

要求：DSH 0.2.x（含 Web GUI），Node.js 22+。

### 从本地目录

在 DSH 里打开插件管理，使用 `install_bundle`，目标指向本 README 所在目录（包含 `package.json` 的那一层）：

```text
<克隆目录>/dsh-appearance
```

安装后在插件列表启用 `dsh-appearance`，刷新页面。

### 从 GitHub

```bash
git clone https://github.com/LiueCreater/dsh-appearance.git
```

然后同样用 `install_bundle` 指向克隆下来的 `dsh-appearance` 目录。

## 使用

- 入口：**设置 → 啥鱼外观**（`settings.section`，order 5），导航图标为自绘相框山景。
- 侧栏底部：设置按钮上方（`sidebar.footer.action`）。
- 设置页里的改动先进入草稿并在预览中显示；点顶部「保存」才写入配置、应用到整个界面。「放弃更改」回到已保存状态。
- 「快速更改」用于日常调壁纸/玻璃/主题色；「上传新样式」用于导入/导出样式包与重置。
- 浅/深编辑切换只决定**正在编辑哪一套**，不会切换当前主题；保存另一套不会影响当前画面。

## 数据与隐私

存储目录：`$DSH_HOME/dsh-appearance/`（默认 `~/.dsh/dsh-appearance/`）

| 文件 | 内容 |
| --- | --- |
| `config.json` | v2 配置：`profiles.light/dark`、`ui.showUsage` |
| `background-light.bin/.json` | 浅色壁纸与元数据 |
| `background-dark.bin/.json` | 深色壁纸与元数据 |
| `usage.json` | 按日、按会话的 token 账本（保留 30 天） |

- 所有数据只保存在本机；壁纸不会上传到任何第三方。
- 余额请求只发往 `api.deepseek.com`（使用本机 DSH 凭据）或由宿主代为请求账号余额。
- 写入使用临时文件 + rename；配置损坏时会备份为 `.bad-<ts>` 并回退默认值。

## Host 接口

插件注册同源路由，前缀 `/dsh-appearance`：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/state?force=1` | 配置、两套壁纸元数据、余额、今日用量 |
| POST | `/config` | 保存配置（JSON） |
| GET / POST / DELETE | `/background?mode=light\|dark` | 读取（支持 Range）/ 上传 / 删除壁纸 |
| GET | `/export.zip` | 导出样式包 |
| POST | `/import.zip` | 导入样式包（≤ 200 MB，校验通过才应用） |
| GET | `/events` | SSE `state` 事件（25s 心跳） |
| POST | `/refresh` | 强制刷新余额 |
| GET | `/health` | 健康检查 |

安全约束：

- Host 必须是 loopback（`127.0.0.1` / `localhost` / `[::1]`），或在 `DSH_APPEARANCE_TRUSTED_HOSTS` 中显式列出。
- 拒绝跨站 `Sec-Fetch-Site`；带 `Origin` 时必须与 `Host` 完全一致。
- 请求体有大小上限；ZIP 解析拒绝路径穿越、加密条目、ZIP64 与重复条目。

## 已知限制

- 窗口最顶部的「应用 / 编辑」是 Electron 原生菜单，渲染层无法改色。
- 桌面端没有向渲染层开放退出/重启接口，插件只能重新加载页面；彻底重启请用托盘或窗口菜单退出。
- 第三方插件自己的配置页文本框由其自身样式控制，本插件不去改写。
- 媒体格式取决于 Chromium 的解码能力；AVIF/HEVC 等在部分平台可能不可播。

## 开发

```bash
npm run check          # node --check 所有入口
```

手动验证：

1. 插件管理器里 disable → enable `dsh-appearance`，刷新页面。
2. 设置 → 啥鱼外观：上传壁纸、调位置/缩放/模糊、切玻璃与主题色、保存。
3. 检查侧栏底部余额/用量、折叠按钮、过程卡玻璃、全屏右侧栏、菜单层级。
4. `GET /dsh-appearance/health` 应返回 `{"ok":true}`。
